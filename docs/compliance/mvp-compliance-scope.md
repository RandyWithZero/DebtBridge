# DebtBridge MVP 合规边界说明

本文档用于约束 DebtBridge 信用卡逾期协商撮合 MVP 的产品、设计、架构和研发实现。平台定位为信用卡逾期协商信息撮合平台，只提供信息展示、需求登记、资质审核、咨询撮合、调解进度记录等服务，不触碰资金、不放贷、不催收、不承诺协商结果。

本文不是法律意见。上线前应由具备相应资质的法律、合规和隐私保护负责人按实际业务主体、经营地、合作机构类型和页面协议进行复核。

## 1. MVP 定位与总原则

### 1.1 平台角色

DebtBridge 在 MVP 阶段只作为信息撮合和流程记录工具：

- 帮助信用卡逾期用户提交协商咨询需求。
- 帮助通过平台审核的合规咨询、调解、法律服务或金融消费者权益服务机构接收用户主动授权后的线索。
- 帮助平台运营人员完成机构准入、线索分配、投诉处理、内容审核、风控审计。

平台不得被设计、宣传或实际运营为：

- 资金清分、代收代付、还款通道或支付中介。
- 贷款、转贷、垫资、债务重组资金提供方。
- 发卡银行、受托催收机构、征信修复机构。
- 结果担保方、债务豁免承诺方或司法代理默认服务方。

### 1.2 必守红线

以下红线必须在产品、协议、运营 SOP、机构准入和客服话术中同步落地：

- 不碰资金：不得代收、代付、保管、归集用户还款资金或服务费保证金。
- 不催收：不得代表银行、机构或第三方对债务人实施催告、施压、骚扰、威胁、曝光通讯录等催收行为。
- 不征信修复：不得承诺删除、屏蔽、洗白、修复、异议撤销合法征信记录。
- 不承诺成功：不得承诺停息挂账、减免息费、延期分期、免诉、免催、征信恢复等结果。
- 不高额预付：不得诱导用户在服务开始前支付高额费用、保证金、通道费、关系费、加急费。
- 不冒充官方：不得使用银行、监管机构、司法机关、仲裁机构、人民调解组织等名义误导用户。
- 不诱导违约：不得建议用户恶意停还、隐匿资产、伪造困难证明、虚构病情或提供不实材料。
- 不过度收集：不得为了初筛收集银行卡密码、验证码、网银登录信息、完整信用卡号、通讯录、短信、位置轨迹等非必要信息。
- 不二次售卖：不得将线索出售给未经审核或未获用户授权的第三方。

### 1.3 监管与合规依据关注点

研发和运营应至少围绕以下规则设计控制项：

- 《中华人民共和国个人信息保护法》：个人信息处理应有明确目的、最小必要、公开透明；敏感个人信息包括金融账户、行踪轨迹、特定身份、医疗健康等，处理敏感个人信息通常需要单独同意，并告知必要性及对个人权益的影响。
- 《商业银行信用卡业务监督管理办法》：信用卡发卡、授信、欠款催收等属于银行信用卡业务链条，平台不得包装成发卡银行或受托催收主体。
- 债务催收行业自律要求和消费者权益保护要求：禁止骚扰、恐吓、误导、冒用机关身份、向无关第三人披露债务信息等不当催收行为。DebtBridge MVP 不做催收，但应把这些行为列入机构禁令和投诉处置规则。

## 2. 角色能力边界

### 2.1 欠款人端

允许能力：

- 查看平台定位、服务流程、风险提示、免责声明、隐私政策、用户协议。
- 主动填写协商咨询需求，包括逾期概况、银行名称、期望沟通方式、可联系时间。
- 上传必要证明材料，前提是页面逐项说明用途、敏感性、保存期限和授权范围。
- 选择是否授权平台将信息推送给指定或匹配的合规机构。
- 查看已授权机构信息、服务说明、收费规则、投诉渠道。
- 撤回授权、删除未进入法定留存或争议处理范围的非必要材料。
- 对机构进行投诉、撤销匹配、拒绝继续沟通。

禁止能力或禁止引导：

- 不提供“代还款”“代扣款”“资金托管”“垫资结清”等入口。
- 不提供“保证停息挂账”“保证减免”“保证不上门”“保证不上征信”等结果型承诺按钮或选项。
- 不引导用户上传银行卡密码、短信验证码、支付密码、网银登录凭证、完整卡面照片、完整通讯录。
- 不引导用户生成、购买或提交虚假困难证明、病历、收入证明、失业证明。
- 不引导用户停止与银行官方渠道沟通或拒绝合法通知。

### 2.2 机构端

允许能力：

- 提交机构主体资质、人员资质、业务说明、收费规则、投诉处理联系人。
- 在通过平台人工审核后接收用户明确授权范围内的线索。
- 查看与服务履行必要相关的用户资料和材料。
- 记录咨询、调解、协商辅助进度，例如“已联系用户”“已提醒用户准备材料”“用户自行联系银行中”。
- 上传服务协议、授权委托文件或沟通记录，但不得替代用户作出还款承诺。
- 接收平台风控抽查、用户投诉处理和准入复核。

禁止能力或禁止行为：

- 不得收取或经手用户还款资金，不得提供平台外资金归集账户。
- 不得以银行、监管、法院、公安、仲裁、人民调解组织等身份联系用户。
- 不得催收、恐吓、骚扰、侮辱、公开债务信息或联系无关第三人施压。
- 不得承诺协商成功、征信修复、债务核销、司法免诉、内部通道。
- 不得诱导用户高额预付或以“保证金”“关系费”“通道费”规避服务费披露。
- 不得把平台线索转卖、转包、共享给未经平台审核且未经用户授权的第三方。
- 不得要求用户提供银行卡密码、验证码、完整卡号、网银登录凭证、通讯录。
- 不得伪造或指导伪造证明材料。

### 2.3 后台运营端

允许能力：

- 审核机构资质、人员资质、服务范围、收费模板和协议模板。
- 管理机构准入状态、线索分配规则、用户投诉、争议处理、内容审核。
- 查看必要的用户资料和材料，用于审核、投诉处理、安全风控和法定义务履行。
- 配置敏感字段脱敏、权限分组、下载审批、操作审计、数据保留策略。
- 下架违规机构、冻结线索分发、发起人工复核、导出合规审计材料。

禁止能力或禁止设计：

- 不提供批量导出完整身份证件、证明材料、联系方式的普通运营权限。
- 不允许运营人员手工改写用户授权状态、替用户勾选同意或绕过机构准入。
- 不允许无审计地查看、下载、复制、转发用户敏感材料。
- 不允许运营人员代机构向用户作出结果承诺、收费承诺或银行内部关系暗示。
- 不允许在后台展示银行卡密码、验证码、完整信用卡号等本不应收集的信息。

## 3. 表单字段、敏感信息与最小化收集

### 3.1 欠款人基础表单

建议 MVP 初筛只收集以下字段：

| 字段 | 是否敏感 | MVP 建议 | 说明 |
| --- | --- | --- | --- |
| 姓名 | 个人信息 | 必要时收集 | 用于机构联系和协议签署；列表页默认脱敏。 |
| 手机号 | 个人信息 | 必填 | 用于联系和登录验证；导出需审批。 |
| 所在城市 | 个人信息 | 可选 | 用于匹配本地服务能力；不要收集精确定位。 |
| 逾期银行名称 | 金融相关信息 | 必填 | 用于匹配经验领域；不收集完整卡号。 |
| 逾期金额区间 | 金融相关信息 | 必填，区间化 | 用区间代替精确金额，降低暴露风险。 |
| 逾期期限区间 | 金融相关信息 | 必填，区间化 | 例如 0-30 天、31-90 天、90 天以上。 |
| 当前诉求 | 个人陈述 | 必填 | 例如延期、分期、咨询材料准备。不得预设“保证成功”。 |
| 可联系时间 | 个人信息 | 可选 | 只用于服务联系。 |
| 是否已收到诉讼/仲裁/催收通知 | 可能敏感 | 可选 | 用于风险分层；不得据此承诺免诉。 |

### 3.2 证明材料

证明材料通常包含敏感个人信息，应遵循“先咨询后补充、按需上传、逐项授权”的原则。

可在明确必要时收集：

- 身份证明材料：用于签署服务协议或身份核验时才收集；默认水印、脱敏展示。
- 收入或失业证明：用于协商材料准备时才收集。
- 医疗、疾病、残疾、家庭困难证明：属于高度敏感信息，仅在用户明确选择相关诉求且单独同意后收集。
- 银行账单或信用卡账单截图：只允许上传必要页面，提示用户遮盖完整卡号、交易对手、无关交易。
- 诉讼、仲裁、律师函、银行通知：用于判断紧急程度和材料准备。

禁止收集：

- 银行卡密码、支付密码、短信验证码、动态口令、网银或手机银行登录凭证。
- 完整信用卡号、完整银行卡磁道/芯片信息、CVV/CVC、有效期。
- 通讯录、通话记录、短信内容、精确定位轨迹。
- 与协商需求无关的家庭成员身份证件、未成年人信息、照片、病历。
- 可由用户自行向银行或法院官方渠道查询、但平台没有必要留存的完整原始资料。

### 3.3 机构资质资料

机构资质可能包含营业执照、法定代表人信息、员工执业证照、授权书、合同模板等。平台应将其作为准入审核材料和持续合规材料管理，不得对欠款人公开展示完整证件号码或无关个人信息。

## 4. 页面、协议、表单必须出现的免责声明

以下文案可直接用于页面、协议和表单。研发实现时应确保关键提示在提交前可见，不只隐藏在协议链接中。

### 4.1 首页和服务介绍页

> DebtBridge 是信用卡逾期协商信息撮合平台，仅提供信息展示、需求登记、咨询撮合和流程记录服务。平台不放贷、不代还、不代收代付、不经手还款资金，不代表银行、法院、监管机构或征信机构，不提供催收服务，也不承诺任何协商结果。

> 信用卡还款、减免、延期、分期、诉讼处理和征信记录以发卡银行、司法机关、监管规则及您的实际情况为准。任何“保证停息挂账”“保证减免”“保证征信修复”“内部通道”等表述均不代表平台承诺。

### 4.2 用户提交表单页

> 您提交的信息将用于评估咨询需求、匹配合规服务机构和处理后续投诉。请勿上传银行卡密码、短信验证码、支付密码、完整信用卡号、通讯录、与本次咨询无关的证明材料或虚假材料。

> 逾期金额、银行账单、困难证明、医疗健康、收入状况等可能属于敏感个人信息。您提交前应确认相关信息确为本次咨询必要，并同意平台在本页面说明的目的、范围和保存期限内处理。

> 提交需求不代表银行同意协商方案，也不代表平台或服务机构承诺协商成功。您仍应通过银行官方渠道核实账户状态、还款安排、费用减免和征信记录。

### 4.3 授权匹配机构弹窗

> 您授权 DebtBridge 将本次咨询所必需的信息提供给您选择或平台匹配的服务机构，用于联系您、了解需求和提供咨询/调解辅助服务。未经您另行同意，机构不得将您的信息转交、出售或共享给其他第三方。

> 您可以撤回授权。撤回后，平台将停止继续向该机构提供您的信息，但不影响撤回前基于您授权已经开展的必要处理活动。

### 4.4 机构详情页

> 本机构为平台准入审核通过的第三方服务机构，不代表银行、司法机关、监管机构或征信机构。机构服务能力、收费项目、协议条款和沟通结果由机构依法自行承担责任。请勿向机构支付还款资金、保证金、通道费或向其提供银行卡密码、验证码等敏感凭证。

### 4.5 服务协议核心条款

> 平台服务范围限于信息撮合、咨询需求登记、机构准入审核、线索授权流转、流程记录、投诉处理和必要的合规风控。平台不参与资金收付，不提供贷款或垫资，不从事催收，不作为银行、机构或用户任何一方的代理人作出还款、减免、延期、分期或征信处理承诺。

> 用户应保证提交材料真实、合法、必要，不得提交虚假证明或侵犯他人权益的材料。因用户提交不实材料或绕过平台与第三方交易产生的风险，由相关责任方依法承担。

> 机构不得作出结果承诺，不得诱导高额预付，不得实施催收或骚扰行为，不得要求用户提供银行卡密码、短信验证码、完整卡号、通讯录等非必要信息。平台发现违规后可暂停或终止合作、冻结线索分发、配合投诉和监管处理。

## 5. 机构准入人工审核清单

上线前必须人工审核并留痕，禁止纯自动化准入。

### 5.1 主体资质

- 营业执照或依法设立证明，核验主体名称、统一社会信用代码、经营状态、经营范围。
- 法定代表人或负责人身份证明，仅限审核使用，后台脱敏展示。
- 实际经营地址、客服电话、投诉联系人和工作时间。
- 与信用卡逾期咨询、调解、法律服务、金融消费者权益服务相关的业务说明。
- 如涉及法律咨询、律师服务、人民调解、金融服务外包等特定业务，应提供相应执业许可、备案、授权或合作证明。

### 5.2 人员与服务资质

- 直接服务人员名单、岗位职责、培训记录、保密承诺。
- 律师、基层法律服务工作者、调解员、金融从业人员等证照或任职证明，按其宣称身份逐项核验。
- 标准服务流程、服务边界、材料清单、沟通话术。
- 禁止承诺结果、禁止征信修复、禁止催收、禁止高额预付的书面承诺。

### 5.3 收费与协议

- 服务协议模板、授权委托模板、隐私或保密条款。
- 收费项目、收费时点、退款规则、发票主体。
- 禁止设置“保证金”“通道费”“关系费”“加急成功费”等高风险项目。
- 预付费必须低额、透明、可退规则清晰；高额预付机构不得准入 MVP。

### 5.4 历史风险与持续管理

- 公开投诉、行政处罚、司法案件、失信被执行、异常经营记录检索。
- 近 12 个月重大投诉和争议说明。
- 每季度复核资质、收费、话术、投诉率和线索处理质量。
- 建立一票否决：冒充官方、催收骚扰、索要密码验证码、转卖线索、伪造材料、承诺征信修复、经手还款资金。

## 6. 存储、访问控制与审计要求

### 6.1 数据分级

- 一级：公开信息，例如平台介绍、服务流程、机构公开简介。
- 二级：普通个人信息，例如姓名、手机号、城市、联系时间。
- 三级：金融和逾期相关信息，例如银行名称、逾期金额区间、逾期期限、账单截图。
- 四级：高度敏感材料，例如身份证件、医疗健康、收入证明、诉讼材料、完整银行通知。

### 6.2 存储要求

- 敏感材料对象存储应加密，数据库字段按需加密或哈希化，备份同等保护。
- 身份证件、账单、医疗材料等文件必须加水印，水印至少包含用户 ID、查看人、时间。
- 默认不保存原图 EXIF 信息；上传后清理定位、设备等元数据。
- 对逾期金额尽量区间化保存；非必要不保存完整卡号，如误上传应提示遮盖并提供删除重传。
- 设置数据保留期限：未匹配线索建议 90 天内清理；已匹配线索按服务履行、投诉处理和法定义务设定期限；超期自动归档或删除。

### 6.3 访问控制

- 欠款人只能访问本人提交的信息、授权状态和匹配记录。
- 机构只能访问被授权且与服务履行必要相关的线索，不得跨机构查询。
- 运营权限按岗位最小化分配，普通客服默认只看脱敏信息。
- 查看四级敏感材料应触发二次确认和操作审计；下载、批量导出、跨机构转派需审批。
- 生产数据库和对象存储不得给研发人员常态化直连权限；排障使用临时授权和脱敏样本。

### 6.4 审计与风控

- 记录用户授权、撤回、机构查看、文件下载、线索转派、后台改动、投诉处理全链路日志。
- 对高频查看、批量下载、非工作时间访问、跨区域异常访问设置告警。
- 对机构话术、页面宣传、收费项目进行抽检，发现“保证成功”“征信修复”“内部通道”等词汇进入人工复核。
- 投诉涉及资金、催收、冒充官方、隐私泄露时应立即暂停该机构新增线索。

## 7. 研发落地注意事项

- 所有同意和授权应可追溯：记录版本号、文案快照、勾选时间、IP、设备、授权对象和授权范围。
- 敏感个人信息同意应单独勾选，不应与用户协议、隐私政策合并成一个总勾选。
- 页面提交前做敏感凭证拦截提示，例如识别“验证码”“密码”“完整卡号”等高风险输入。
- 机构端和后台端的文件预览默认脱敏、水印、禁止普通角色下载。
- 线索分发必须检查机构状态、服务范围、用户授权和投诉冻结状态。
- 不要在日志、埋点、客服系统、错误监控中记录身份证号、账单原图、医疗材料、完整手机号等敏感数据。
- 所有外部通知短信和站内消息不得披露“逾期”“欠款”“债务”等敏感语义给非本人可见渠道。
- 管理后台要有紧急下架机构、冻结线索分发、撤回机构访问权限的开关。

## 8. MVP 上线前检查清单

- 页面和协议已展示“不碰资金、不催收、不征信修复、不承诺成功、不高额预付”等红线。
- 欠款人端、机构端、后台端均已按角色做最小权限控制。
- 所有敏感字段均有用途说明、单独同意、脱敏展示和访问审计。
- 机构准入资料已人工审核并留痕，违规一票否决规则已配置。
- 投诉入口、隐私撤回入口、机构举报入口可用。
- 线索推送只发生在用户明确授权后，且推送对象为已准入机构。
- 支付、代扣、代还、资金托管、催收任务、征信修复承诺等能力未进入 MVP。
- 运营、客服、机构人员已完成红线培训和话术审核。
